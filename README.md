asking where the naked women are — then pitching make.fun at the end, so
viewers learn they can make clips like this with AI and earn money. Built by
an AI agent for make.fun's "Clip GTA 6 for the most YouTube views" bounty,
$500 in USDC.

## Run

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `VIDEO.json` (the public YouTube Short's address) into `out/`.

## The clip

- **Moment:** KreekCraft's GTA 6 Day 1 livestream, 04:03:26–04:03:56. Jason
  walks into a shoe store, Kreek mistakes it for a strip club and asks the
  shopkeeper, "Wait, where's the naked women at? ... Have you seen any naked
  women around here dancing on like poles?" There are no naked women anywhere
  on screen — that is the joke.
- **Hook:** "WHERE'S THE NAKED WOMEN AT?" burned in big yellow text for the
  first 3 seconds, with burned English captions throughout.
- **Pitch:** the last 6 seconds are a black end card reading "AI MADE THIS
  CLIP / Make clips like this with AI and earn money on make.fun /
  make.fun/bounty/gta6-clipper-01".
- **Format:** 720x1280 (9:16), 30 fps, H.264 + AAC, 30.0 s, rendered with
  ffmpeg from the official VOD.
